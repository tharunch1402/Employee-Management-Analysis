# Employee Management System (SQL Project)

## Project Overview

The Employee Management System is a SQL-based database project designed to manage and organize employee-related data in a centralized system. The project addresses common HR problems where employee information is scattered across multiple files or systems, making it difficult to track payroll, leave, qualifications, and department-wise details efficiently 
This system stores employee, job, salary, qualification, leave, and payroll information in well-structured relational tables, ensuring data accuracy, consistency, and easy reporting.

# Business Problem

Many organizations face challenges in managing employee data due to:
 
1. Manual record keeping and scattered data
2. Errors in payroll calculations
3. Difficulty in tracking leaves and qualifications
4. Lack of clear department-wise and salary insights
5. This project solves these issues by providing a centralized database solution for HR operations

## Project Objectives

1.Store employee personal and job-related details in a structured database
2. Manage salary, bonus, and payroll information accurately
3. Track employee qualifications and leave records
4. Maintain data integrity using primary keys, foreign keys, and relationships
5. Enable easy SQL querying for HR analysis and reporting
6. Reduce manual work and errors in employee data management 

# Database Tables

The project consists of the following main tables:

1. Job Department – job roles, departments, descriptions, and salary ranges

2. Salary Bonus – salary amounts and bonus details

3. Employee Details – employee personal and job information

4. Qualification Details – employee qualifications and positions

5. Leave Details – employee leave records

6. Payroll Details – payroll processing with salary, leave, and total amount

All tables are connected using proper relationships and cardinality as shown in the ER diagram 


## Key SQL Analysis Questions

1. Which departments have the highest number of employees?
2. What is the average salary per department?
3. Who are the top 5 highest-paid employees?
4. What is the total salary expenditure of the company?
5. Which employees have the most qualifications?
6. Which year had the highest number of leaves?
7. What is the total monthly payroll processed?
